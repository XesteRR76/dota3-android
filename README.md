# DOTA 3: Ancient Rebirth — 3D Android MOBA

Полноценная **3D** мобильная MOBA в духе Dota 2 / Dota 3 на Android (`OpenGL ES 2.0 3D Engine` + оригинальные арты героев/скиллов/предметов Dota 2 + классический нижний HUD Dota 2 + эргономичное управление в стиле MLBB).

## Что нового в v3.3.0
- **Улучшенный 3D-движок и детализированные модели (`World3DRenderer` + `Mesh3D`)**:
  - Запечённая текстура карты `384x384` + попиксельный шейдер брусчатки линий, плавных берегов реки с бликами воды, базы Radiant/Dire, арены Рошана, атмосферного тумана войны и контурной подсветки (rim lighting).
  - Уникальные 3D-модели всех 12 героев (катана, двойные глефы, топор, тотем, посохи, снайперская винтовка, астролябия Хроноса, короны/рога/шлемы, анимации ударов и 3D-слеши), армированные крипы со щитами, катапульты, вышки-кристаллы, Троны Древних и Рошан.
- **Классический нижний HUD как в Dota 2 + MLBB-эргономика под пальцы (`HudGeometry` + `MlbbHudOverlayView`)**:
  - Нижняя консоль героя: портрет из Dota 2, значок уровня, шкала XP и тап-центрирование камеры.
  - Атрибуты `STR/AGI/INT`, `DMG/ARM/MS/AS`, кнопка Древа Талантов, индикаторы `Scepter/Shard`, полоса активных баффов, сетка предметов `3x2`, слоты `TP` и нейтрального предмета.
  - Удержание `ATK`/`CREEP`/`TWR/!`, умное прицеливание и отмена `CANCEL X` прямо над дугой скиллов, перетаскивание прицела активных предметов (`Blink`, `Ward`, `Hex`), кнопка `ZOOM` + pinch-to-zoom и фикс дистанции атаки для дальников.
