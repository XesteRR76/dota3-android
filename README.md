# DOTA 3: Ancient Rebirth — 3D Android MOBA

Полноценная **3D** мобильная MOBA в духе Dota 2 / Dota 3 на Android (`OpenGL ES 2.0 3D Engine` + оригинальные арты героев/скиллов/предметов Dota 2 + классический нижний HUD Dota 2 + эргономичное управление в стиле MLBB).

## Что нового в v3.4.0
- **Надёжность OpenGL ES 2.0 и 3D-графика (`World3DRenderer` + `Mesh3D`)**:
  - Запечённая POT-текстура карты `512x512` (брусчатка, круги рун, перепады высот) + POT туман войны `128x128`, `highp` точность фрагментного шейдера и корректное масштабирование нормалей (`uInvScale`) для чёткого освещения на Adreno/Mali GPU.
  - Потокобезопасная синхронизация GL-потока и UI (`synchronized(world)`), доработанное крепление и наклон 3D-оружия героев (двойной топор Axe, тотем Earthshaker, молния Zeus, посохи магов, катана, глефы), анимация магов/катапульт и более естественные органические леса.
- **Dota 2 консоль и удобное управление пальцами (`HudGeometry` + `MlbbHudOverlayView`)**:
  - Подписанные столбцы атрибутов `STR / AGI / INT`, индикатор доступных очков скиллов `+SP`, авто-подгон текста HP/MP и регенерации без наложений, отметки активных предметов, визуальный круг прицела предметов (`Blink`, `Ward`, `Hex`) и чёткий кулдаун на `TP`.
  - Более компактная и удобная дуга скиллов `Q/W/E/R` под правый палец, увеличенные кнопки `+ LVL`, корректное масштабирование дальности AoE-прицела, умный `TP` (на базу с линии / на линию с фонтана), джойстик строго в нижней левой зоне, ролевой Quick-Buy и фиксация полноэкранного режима после закрытия диалогов.
